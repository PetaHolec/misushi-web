# MiSushi – návrh nového webu

Koncept redesignu webu restaurace MiSushi (Národní 63/26, Praha 1).

- Jedna statická stránka (`index.html`), bez build kroku
- Mobile-first, lightbox galerie (swipe, pinch/klepnutí pro zoom)
- Fotky se zatím načítají z misushi.cz, recenze jsou ukázkové texty
- Stránka má `noindex` – jde o koncept, ne o oficiální web

Lokálně: `python3 -m http.server 5173`
